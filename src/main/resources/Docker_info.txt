Docker image recommendation:
- mahfuzdocker20/testdb_api:latest

1. Build the Spring Boot image locally

Command:
docker build -t mahfuzdocker20/testdb_api:latest .

What it does:
- Builds the application image from the Dockerfile in the project root.
- Packages the Spring Boot app into a Java 17 runtime image.

2. Run the full stack with MySQL by using Docker Compose

Command:
docker compose up --build

What it does:
- Starts a MySQL 8 container named testdb_mysql
- Builds and starts the Spring Boot app container named testdb_api_app
- Exposes the API on:
  http://localhost:8080

3. Useful Docker commands

Check running containers:
docker compose ps

View app logs:
docker compose logs -f app

Stop the stack:
docker compose down

4. Push this project image to Docker Hub

Recommended image tag:
docker build -t mahfuzdocker20/testdb_api:latest .

Login:
docker login

Push:
docker push mahfuzdocker20/testdb_api:latest

Optional extra version tag:
docker tag mahfuzdocker20/testdb_api:latest mahfuzdocker20/testdb_api:v1
docker push mahfuzdocker20/testdb_api:v1

5. Pull and run from Docker Hub

Pull:
docker pull mahfuzdocker20/testdb_api:latest

Run only the application container:
docker run -p 8080:8080 mahfuzdocker20/testdb_api:latest

Important note:
- The application needs MySQL.
- If you run only the app image, make sure it can reach a MySQL database through the environment variables below.

Required environment variables for containerized deployment:
- SPRING_DATASOURCE_URL
- SPRING_DATASOURCE_USERNAME
- SPRING_DATASOURCE_PASSWORD
- SPRING_JPA_HIBERNATE_DDL_AUTO
- SERVER_PORT

Example:
docker run -p 8080:8080 ^
  -e SPRING_DATASOURCE_URL=jdbc:mysql://host.docker.internal:3306/testdb?useSSL=false^&allowPublicKeyRetrieval=true^&serverTimezone=UTC ^
  -e SPRING_DATASOURCE_USERNAME=root ^
  -e SPRING_DATASOURCE_PASSWORD=root ^
  -e SPRING_JPA_HIBERNATE_DDL_AUTO=update ^
  -e SERVER_PORT=8080 ^
  mahfuzdocker20/testdb_api:latest

6. Repository description for Docker Hub

Suggested short description:
- Spring Boot 4 REST API for user data with MySQL 8, Docker, and Docker Compose support.

Suggested overview:
- This project is a Spring Boot 4 REST API that manages user records stored in MySQL.
- It supports create, read, update, patch, delete, range selection, limited fetch, and ID-based selection endpoints.
- The repository includes Docker and Docker Compose configuration for local development and containerized deployment.

7. Current API base URL

Local:
- http://localhost:8080/users

Main endpoints:
- GET /users
- GET /users/limit?size=3
- GET /users/range?start=0&end=3
- GET /users/select?ids=1,2,3
